# v1.0.7

- 明暗主题、原生背景和系统栏使用平滑过渡；减弱白天右上角按钮的顶部高光。
- 日期栏和课程区域左右滑动均按一天切换，跨周自动跟随；保留周切换按钮。
- 点击课程查看日期、节次、时间、教室和教师；点击正在上课或下一节提示返回今天。
- 时间表和校园地图等待图片解码完成后打开，保持不透明背景，减少闪动。
- 导入课表、学期与作息、上课提醒、桌面小组件改为独立二级页面。
- 去除启动重复加载，缓存日期格式器和课程索引，作息字段按需生成。

## 安装

最低 Android 8.0。本版使用新的固定签名，与本次提供的新签名 v1.0.6 相同，可覆盖更新该版本。旧签名版本和临时签名预览版无法直接覆盖。请先保留课表导入文件或备份数据。

私钥与密码不随仓库发布；后续自行构建需使用安全保存的密钥。

## 验证

通过 Chrome 触屏回归：5,000 条课程、按天滑动与跨周、键盘、主题、减少动态效果、延迟图片加载、课程详情、返回今天、四个二级页面及返回操作。
通过 Android Java 编译、资源打包、DEX 生成、APK 签名验证及与新签名 v1.0.6 的证书一致性核对。
动画观感和启动耗时尚需手机实机验证。
