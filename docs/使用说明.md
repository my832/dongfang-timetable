# 两款应用

| 应用 | 版本 | 内容 |
| --- | --- | --- |
| 拾记 | 1.4.8 | 便签记录、课表、上课提醒、便签和课程桌面小组件 |
| 东方课表 | 1.0.3 | 独立课表、上课提醒、课程桌面小组件、明暗切换 |

支持 Android 8.0 及以上。两款可以同时安装，使用独立的数据目录和通知设置。
拾记可以覆盖安装旧版，保留便签和课表；独立版首次安装后导入自己的课表。

## 直接导入

拾记点顶部日历，再展开“导入课表”。独立版点右上角导入按钮。
在线导入必须连接校园网并关闭代理。联网失败、加载失败或超时时会提示检查网络并刷新。
输入教务账号和密码，点“登录教务并导入”。内置浏览器使用学校网页的登录逻辑。
登录成功后自动进入个人课表、识别并保存，无需再点导入或确认。密码不保存，返回时清理登录会话。
如果学校要求验证码或登录协议，需要在网页完成这一步。

已内置学校 2026–2027 学年两学期校历和 13 节作息。
识别到对应学期时自动生成实际上课日期，按单双周安排匹配完整时间。
同一学期重新导入保留自己的作息修改和提醒设置；未知学期需要填写教学周起始日期。
保留 HTML / JSON 文件导入，文件识别结果仍需确认后替换已有课表。
学校临时调课后重新导入。

## 提醒与小组件

展开“上课提醒”，开启提醒并允许通知，默认开课前 20 分钟提醒。
可以授权准时提醒，并在红米 K70 的系统设置开启自启动和无限制省电。
只提醒实际有课的日期，同一时间合并通知，结束的课不会重复提醒。
两款各自有“今日课程”小组件；拾记另有“常驻便签”。长按桌面可以添加和调整大小。
